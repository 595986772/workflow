# 正式实验方法清单

> 冻结日期：2026-08-20。论文展示名统一使用 `OUR`，不再使用 `HERO-DAG`。代码内部标签仅用于结果追溯，不进入图例、正文标题或贡献列表。

## 主对比实验

| 实验身份 | 正式方法名 | 缓存机制 | 卸载策略 |
|---|---|---|---|
| 启发式基线 | Random | 独立流行度缓存 | 随机服务器 |
| 启发式基线 | Nearest | 独立流行度缓存 | 最近服务器 |
| 启发式基线 | SA-Nearest | 独立流行度缓存 | 服务感知最近服务器 |
| 学习基线 | DQN-NoDSA | DAOC-Cache | 基础DQN，无DAOC动作引导 |
| 学习基线 | SAC + DAOC-Cache | DAOC-Cache | Discrete SAC |
| 直接基线 | DAOC | DAOC-Cache | DAOC DQN |
| 受控组合 | DAOC + DCC | DCC | DAOC DQN |
| 受控组合 | DDQN + DCC | DCC | Flat Double DQN |
| 同缓存强基线 | SAC + DCC | DCC | Discrete SAC |
| 提出方法 | OUR | DCC | Pairwise PD3QN |

## 机制消融与因子组合

| 正式方法名 | 作用 | 论文结论边界 |
|---|---|---|
| PD3QN + DAOC-Cache | 固定Pairwise PD3QN，移除DCC | 与`DDQN + DCC`、DAOC和OUR构成2×2受控比较 |
| OUR-noTaskDependency | 移除调度状态中的任务依赖信息 | 显著退化，可支持任务依赖状态的作用 |
| OUR-noDependencyCache | 移除缓存评分中的DAG依赖修正 | 未显著退化，不能列为独立创新 |
| OUR-TerminalReward | 将增量奖励替换为二元终局奖励 | 仅证明相对二元终局奖励的收益，不等价于纯Terminal-Makespan消融 |
| OUR | 完整DCC + Pairwise PD3QN | 完整方法 |
